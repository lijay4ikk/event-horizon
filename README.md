# EVENT HORIZON

3D-сайт студии в виде полёта к чёрной дыре. Чистые HTML, CSS и JS, без сборки. Three.js и Lenis лежат локально в `vendor/`.

## Запуск

Просто откройте `index.html` двойным щелчком. Весь код собран в `js/bundle.js`, сервер не нужен.

Чтобы открыть на телефоне в той же Wi-Fi-сети:

```bash
python3 -m http.server 8765 --bind 0.0.0.0
# на телефоне: http://<IP компьютера>:8765
```

После правок исходников в `js/` нужно пересобрать бандл командой `./build.sh` (нужен Node.js).

Для деплоя подойдёт любой статический хостинг (Vercel, Netlify, GitHub Pages, nginx).

| T | Сцена | Что внутри |
|---|-------|------------|

## Пасхалки

- `↑↑↓↓←→←→BA` включает гиперскорость ×5
- `STAY` в поле сообщения: решётка мигает азбукой Морзе
- «Вернуться на Землю ↑» перематывает весь полёт назад

## Форма → Telegram

Заявки уходят в Telegram через Cloudflare Worker (`worker/`), адрес задан в `index.html`:

```html
<meta name="eh-form-endpoint" content="https://event-horizon-form.kunymmenin.workers.dev">
```

Worker принимает заявки только с сайта (`ALLOWED_ORIGINS` в `worker/wrangler.toml`), отсеивает ботов
(скрытое поле-ловушка, слишком быстрое заполнение), ограничивает частоту (5 заявок в минуту с IP)
и пересылает сообщение боту. Ключ бота и ваш ID хранятся только в секретах Cloudflare:

```bash
cd worker
npx wrangler@4 secret put BOT_TOKEN   # ключ от @BotFather
npx wrangler@4 secret put CHAT_ID     # ваш ID от @userinfobot
npx wrangler@4 deploy                 # после правок worker/src/index.js
```

Если адрес пустой, форма работает в демо-режиме: заявка никуда не уходит.

## Качество и отладка

- Уровень GPU определяется автоматически (high / medium / low), дальше регулятор FPS сам снижает разрешение трассировки и число шагов.
- `?q=high|medium|low` принудительно задаёт уровень, `?nogov` отключает регулятор.
- `?nowebgl` открывает статичную версию (фоны — настоящие кадры сцен из `assets/frames/`), `?rm` включает режим «меньше движения», `?clean` прячет интерфейс (для снятия кадров), `?lang=en|ru` задаёт язык, `?autostart` пропускает прелоадер.
- Поддерживается `prefers-reduced-motion`: без тряски, warp и аберрации, со скроллом без инерции.

## Структура

```
index.html            разметка (весь текст в HTML, SEO, JSON-LD)
css/style.css         HUD-стиль, адаптив, статичная версия
js/main.js            оркестрация: прелоадер, скролл, кадр, UI
js/gfx/shaders.js     GLSL: ЧД, кротовая нора, туннель, тессеракт, пост
js/gfx/pipeline.js    render targets, bloom, анаморфный блик, грейдинг
js/gfx/cosmos.js      полноэкранные слои
js/scene/*.js         траектория камеры, станция, планеты, частицы, галерея
js/audio.js           синтез звука Web Audio (без сэмплов)
js/artgen.js          генеративные обложки работ
js/content.js         тексты работ и услуг (RU/EN)
js/i18n.js            переводы
```

Все изображения, звуки и модели создаются кодом. Материалы фильма не используются.

## Статистика → Telegram

Своя аналитика без сторонних сервисов: `js/analytics.js` шлёт лёгкие сигналы на тот же Worker (`/t`),
он складывает их в Cloudflare D1 (`worker/schema.sql`) и каждый день в 09:00 МСК присылает сводку в Telegram
(по понедельникам — ещё и за неделю). Команды бота: `/stats` (сегодня), `/yesterday`, `/week`.

Что считается: посетители и визиты, кто начал полёт (и со звуком ли), до какой сцены долетели, время на сайте,
страны и города, устройства и браузеры, откуда пришли, какие планеты и работы открывали, заявки, пасхалки.

Приватность: IP не хранится (из IP, браузера и даты получается одноразовый суточный код), cookies нет,
данные старше 90 дней удаляются. Не считаются роботы, Do Not Track / GPC и кнопка «отключить» в футере.
Чтобы не учитывать свои заходы, откройте сайт один раз со ссылкой `?notrack` на каждом своём устройстве.
